# Spark 饰品百货

React + Vite 的饰品百货前端演示站，包含 3 个类目、45 个本地 WebP 商品图、购物车侧栏、Buy Now 结算页、支付方式展示、政策页和后台演示入口。

## 开发

```bash
npm.cmd run dev
npm.cmd run build
```
